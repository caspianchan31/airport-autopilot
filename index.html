Airport Autopilot

机场搭子

An airport game for iPhone and iPad set in the Alps: Innsbruck, with Salzburg and Zurich as separate purchases. Clear every flight yourself, or let the AI manager run the routine work.

一款以阿尔卑斯山下的机场为舞台的机场经营游戏：因斯布鲁克，另有萨尔茨堡、苏黎世单独购买，支持 iPhone 和 iPad。每架航班可以亲手放行，也可以把日常调度交给 AI 经理。
